# Training

A strength-training app: a React + TypeScript + Tailwind + shadcn/ui + lucide project.

- `src/App.tsx`: the screens (Today, Plan, Progress, Settings) in `components/app-shell.tsx`
  (a tab bar on iPhone, a sidebar from 900 px).
- `src/lib/training.ts`: the data, JSON in the app's store (`plan`, and the `log` collection),
  started from the note's tables the first time.
- `src/components/ui/`: shadcn/ui components, plain source to edit.
